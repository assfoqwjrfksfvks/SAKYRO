SAKYRO — тестовая сборка для Windows 11 x64

1. Распакуйте архив в обычную папку.
2. Запустите start.bat из распакованной папки.
3. Откройте http://127.0.0.1:4177 в браузере после запуска сервера.

Пока пользуетесь приложением, держите окно start.bat открытым. Закройте его, чтобы остановить сервер.

Node.js и восемь демотреков уже входят в архив. Для запуска достаточно современного браузера. Интернет при первом запуске не требуется. Каталог создаётся в папке data. Избранное, история и плейлисты сохраняются в текущем браузере.

Если порт 4177 занят, скопируйте settings.example.bat в settings.bat и укажите в копии свободный порт. Откройте адрес, который покажет start.bat.
