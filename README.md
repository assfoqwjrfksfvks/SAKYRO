# SAKYRO

Адаптивное веб-приложение музыкального сервиса с восемью оригинальными демотреками. В верхнем меню доступны «Главная», «Поиск», «Любимое» и «Медиатека». На главной «Моя волна» показывает обложку и форму аудиоволны активного трека. Прокрутите экран или нажмите «Подборки и треки», чтобы увидеть миксы, жанры и недавние треки. Здесь и в остальных разделах воспроизведением управляет мини-плеер.

Пробел воспроизводит или приостанавливает трек, стрелки влево и вправо перематывают его на 5 секунд. В полях ввода, элементах выбора и ползунках работают их обычные клавиши.

## Тестовая сборка для Windows

Распакуйте `SAKYRO-Windows.zip` на Windows 11 x64, запустите `start.bat` и откройте `http://127.0.0.1:4177` в браузере. Node.js уже входит в архив, запуск работает без интернета. Чтобы остановить приложение, закройте окно `start.bat`.

Для сборки архива из исходников на Linux или в WSL выполните `npm ci` и `npm run package:windows`. Нужны Node.js 24, Bash, curl, unzip, zip и sha256sum. Готовый архив появится в `out/SAKYRO-Windows.zip`.

## Локальный запуск

1. Установите [Node.js 24 LTS](https://nodejs.org/) с npm.
2. В папке репозитория выполните `npm ci`, затем `npm run dev`.
3. Откройте `http://localhost:3000`. В шапке можно выбрать лавандовый или сиренево-синий акцент.
4. Для остановки нажмите `Ctrl+C` в терминале.

Интернет нужен для установки зависимостей. Шрифты, обложки и демотреки загружаются из самого приложения. FFmpeg понадобится только для перегенерации аудио, инструкция находится в [описании демотреков](public/audio/README.md).

## Проверки и данные

- `npm run check` проверяет типы и маршруты.
- `npm test` проверяет создание и повторное открытие базы, а также наличие медиафайлов для треков.
- `npm run build` собирает приложение. `npm start` запускает собранную версию.
- Сервер применяет миграцию SQLite и заполняет демокаталог при первом запросе к главной. База создаётся в `.data/catalog.sqlite`. Переменная окружения `SAKYRO_DATA_DIR` позволяет указать другую папку для данных.
- Избранное, отметки «Не нравится», история и плейлисты сохраняются в текущем браузере. Настройки «Моей волны» меняют порядок будущих треков по жанрам, лайкам и истории. Демокаталог состоит из инструментальных записей. В режиме «Популярное» используются прослушивания в этом браузере.
