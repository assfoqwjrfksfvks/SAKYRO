# SAKYRO

Адаптивное веб-приложение музыкального сервиса с восемью оригинальными демотреками. На мобильной главной видны «Моя волна», быстрые подборки и недавние треки. Миксы и жанры находятся ниже и доступны при прокрутке или по кнопке «Миксы и жанры».

## Локальный запуск

1. Установите [Node.js 24 LTS](https://nodejs.org/) с npm.
2. В папке репозитория выполните `npm ci`, затем `npm run dev`.
3. Откройте `http://localhost:3000`. Для второго варианта откройте `http://localhost:3000/?variant=b`. Переключатель есть и на самой главной.
4. Для остановки нажмите `Ctrl+C` в терминале.

Интернет нужен для установки зависимостей. Шрифты, обложки и демотреки загружаются из самого приложения. FFmpeg понадобится только для перегенерации аудио, инструкция находится в [описании демотреков](public/audio/README.md).

## Проверки и данные

- `npm run check` проверяет типы и маршруты.
- `npm test` проверяет создание и повторное открытие базы, а также наличие медиафайлов для треков.
- `npm run build` собирает приложение. `npm start` запускает собранную версию.
- Сервер применяет миграцию SQLite и заполняет демокаталог при первом запросе к главной. База создаётся в `.data/catalog.sqlite`. Переменная окружения `SAKYRO_DATA_DIR` позволяет указать другую папку для данных.
- Избранное и история фактических прослушиваний сохраняются в текущем браузере. Очередь, фильтры, поиск и «Моя волна» используют демокаталог. Подбор «Моей волны» учитывает жанры любимых и недавно прослушанных треков.
