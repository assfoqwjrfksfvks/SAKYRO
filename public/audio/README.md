# Демотреки SAKYRO

Восемь коротких инструментальных композиций созданы для этого проекта. Запись синтезирована по оригинальным нотным последовательностям скриптом [`scripts/generate-demo-audio.py`](../../scripts/generate-demo-audio.py) из простых осцилляторов и шума. В файлах нет внешних сэмплов и записей сторонних исполнителей. Имена артистов в демонстрационном каталоге вымышлены.

Готовые MP3 можно воспроизводить сразу. Для повторной генерации из корня проекта запустите `python3 scripts/generate-demo-audio.py`. Чтобы пересоздать только две жанровые композиции, выполните `python3 scripts/generate-demo-audio.py city-lights after-midnight`. Понадобятся Python 3 и FFmpeg с кодеком `libmp3lame`.
